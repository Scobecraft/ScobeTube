    Passkeys 0

    Mit Fingerabdruck, Gesicht oder Bildschirmsperre bestätigen, zum Beispiel über den Google-Passwortmanager, Android, iPhone, Windows Hello oder einen USB-Sicherheitsschlüssel.

    ⚠ Passkeys gehen nur über HTTPS. Du hast ScobeTube gerade über unverschlüsseltes HTTP geöffnet, deshalb blockiert der Browser sie. Richte HTTPS über einen Reverse-Proxy ein (z. B. Nginx Proxy Manager oder Caddy). Bis dahin funktioniert die Authenticator-App.
